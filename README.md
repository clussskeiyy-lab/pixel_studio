# Pixel Studio
Pixel Studio adalah website e-commerce sederhana yang menampilkan katalog produk
lengkap dengan fitur keranjang belanja. Website ini dibangun menggunakan HTML5
dan CSS3 sebagai pemenuhan Tugas mata kuliah Pemprograman Web.

## Tools yang Digunakan
- HTML5
- CSS3

## Anggota & Pembagian Tugas

- **[Muhammad Rifki Maulana] – [2510131210001]**: Penulisan seluruh struktur HTML (pixel_studio.html)
  
## Struktur File
- `pixel_studio.html` — Halaman utama, menampilkan katalog produk & keranjang belanja
- `desain.css` — Stylesheet untuk seluruh halaman (layout, warna, tipografi, responsivitas)
- `img/` — Folder berisi gambar/aset produk
